# nsKnox

> nsKnox is an Israeli fintech-security company that protects business-to-business payments
> against fraud and misdirection for corporations and banks. Its PaymentKnox platform validates
> payee bank-account ownership worldwide and secures outgoing and incoming payment flows.
> Founded and led by Alon Cohen, founder and former CEO of CyberArk.

Generated by API Evangelist (https://apievangelist.com) on 2026-08-26 from the public
nsKnox website. This file is NOT published by nsKnox; nsKnox serves no llms.txt of its own
(https://nsknox.net/llms.txt returns HTTP 404).

## Important for agents

- nsKnox publishes **no public API reference, no developer portal, and no machine-readable
  specification** (no OpenAPI, AsyncAPI, GraphQL SDL, Postman collection, or JSON Schema).
- nsKnox does market API access: "The banks and its corporate clients connect to the
  PaymentKnox platform through a variety of interfaces, including a secured portal, using
  files or an API for accelerated time to protection", and "a full ERP API integration" with
  SAP and Oracle. That API is documented to onboarded customers only.
- The PaymentKnox application backend host is `pknox.nsknox.net` (read from the customer
  portals' own Content-Security-Policy `connect-src`). It sits behind a WAF that rejects
  every unauthenticated request. Do not attempt to call it.
- There is no nsKnox MCP server, no A2A agent card, and no first-party SDK in any package
  registry.
- To obtain API access, use the contact-sales form: https://nsknox.net/contact-us/

## Products

- [Adaptive Payment Security](https://nsknox.net/adaptive-payment-security/): global payee
  bank-account validation combining Quick Check (fast in-network validation against nsKnox's
  proprietary database and partner network, no vendor registration required) and Knox Verify
  (out-of-network mini-transaction that extracts authoritative data directly from the
  supplier's bank).
- [PaymentKnox for Accounts Payable](https://nsknox.net/paymentknox-for-accounts-payable/):
  protection for outgoing payments; integrates with SAP, Oracle and other ERPs via direct API,
  scheduled file transfer, or a no-integration SaaS portal.
- [PaymentKnox for Accounts Receivable](https://nsknox.net/paymentknox-for-ar/): protection for
  incoming payments, including payee registration of validated bank details.
- [Bank Account Certificates](https://nsknox.net/bank-account-certificates/): verified,
  shareable certificates of bank-account ownership.
- [Master Data Guard](https://nsknox.net/master-data-guard/): controls over the vendor master
  file.
- [Payment Check](https://nsknox.net/payment-check/): payment file inspection.
- [Dynamic Positive Pay](https://nsknox.net/dynamic-positive-pay-for-electronic-payments/):
  positive pay for electronic payments.
- [AI Agent Caller](https://nsknox.net/ai-agent-caller/): the PaymentKnox Autonomous Callback
  Agent, which schedules and conducts vendor verification calls in the supplier's native
  language and produces a recording and summary. A product feature, not an agent protocol
  endpoint.

## Technology

- [Cooperative Cyber Security (CCS)](https://nsknox.net/technology/): the patented architecture
  underneath every product. Data is shredded and distributed across multiple independent
  "Knoxer" systems, so no single breach reveals anything.
